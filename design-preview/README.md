# LifeOS Design Preview — Phase 0 + Phase 1

## Обзор

Три интерактивных прототипа интерфейса LifeOS — персональной операционной системы с интеллектуальным секретарём.

**Утверждённое направление**: концепция **B — Intelligent Command Center** (Phase 1: REFINEMENT B). Концепции A и C сохранены как архив первоначального исследования.

**Стек**: Статический HTML/CSS/JS, без зависимостей. Открывается напрямую в браузере.

## Запуск

### Вариант 1: Открыть напрямую
Откройте файл `index.html` каждой концепции в браузере:
- `concept-a/index.html` — Premium Workspace
- `concept-b/index.html` — Intelligent Command Center
- `concept-c/index.html` — Calm Life OS

### Вариант 2: Локальный сервер
```bash
cd design-preview
python -m http.server 8080
# Затем откройте:
# http://localhost:8080/concept-a/
# http://localhost:8080/concept-b/
# http://localhost:8080/concept-c/
```

### Вариант 3: VS Code Live Server
Установите расширение Live Server и откройте `index.html` каждой концепции.

## Экраны (все концепции)

| Экран | Описание |
|-------|----------|
| **Сегодня** | Главный экран: список задач на день, статистика, приоритеты |
| **Входящие** | Быстрый захват задач, обработка входящих |
| **Все задачи** | Полная картина: фильтры, проекты, статусы |
| **Ассистент** | Диалог с ИИ-секретарём |

## Тестовые данные

Все концепции используют одинаковые моковые данные:
- 10 задач (9 активных, 1 просроченная, 1 высокоприоритетная завершённая)
- 5 элементов во входящих
- 3 сообщения ассистента
- Даты привязаны к Europe/Moscow (демо-дата: 9 ноября 2026)

## Интерактивность

- **Переключение экранов**: боковая навигация (desktop), нижняя навигация (mobile)
- **Отметка задач**: чекбокс (мышь + клавиатура Enter/Space)
- **Быстрые фильтры**: Сегодня, Просроченные, Высокий приоритет, Без срока (концепция B)
- **Ассистент**: ввод сообщения, быстрые промпты, статус выполнения, обработка ошибок, повтор запроса
- **Фокус-режим**: кнопка «Начать фокус» (демо)
- **Мобильная адаптация**: responsive, safe-area, нижняя навигация, полноэкранный ассистент

## Безопасность и качество (Phase 1)

- **XSS-защита**: пользовательские данные не вставляются через innerHTML — только через textContent/createElement
- **Даты**: Europe/Moscow, без жёстко зашитой текущей даты
- **Клавиатурная навигация**: чекбоксы, фокус-видимость, Esc для закрытия ошибок, ⌘K для командной строки
- **Демо-маркировка**: все имитирующие действия помечены как «(демо)» — ассистент не заявляет о реальном создании задач

## Режимы просмотра

- **Desktop**: 1440×900 (рекомендуемый)
- **Mobile**: 390×844 и 375×812 (responsive breakpoint 768px, safe-area-inset)

Для проверки мобильного вида: измените размер окна браузера или используйте DevTools (F12 → Toggle device toolbar).

## Клавиатурные сокращения (концепция B)

| Сокращение | Действие |
|-----------|----------|
| Enter / Space | Переключить чекбокс задачи |
| ⌘K / Ctrl+K | Командная строка |
| Esc | Закрыть ошибку / уведомление |
